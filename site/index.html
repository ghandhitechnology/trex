    02the trick
    
      
    Four hops to your pane.
    
      
    trex paints straight into your terminal with the kitty graphics protocol, sixty times a second, right through tmux.
    
    
    
    
    
      
    
        
    
          
    
            256 × 144 · RGB
            
    
          
    
          
    
            KITTY GRAPHICS · ONE FRAME
            
    ESC_Ga=T,U=1,i=229,f=24,s=1024,v=576,c=96,r=27,q=2,t=s,S=1769472;L3RyZXgtNDgyMTMtMA==ESC\
    t=s: the pixels sit in shared memory at /trex-48213-0. The escape only carries the name.
    
            
    trexshm · 1.7 MBkitty
    
          
    
          
    
            TMUX PASSTHROUGH
            
    ESC Ptmux;ESCESC_Ga=T,U=1,i=229,…;L3RyZXgtNDgyMTMtMA==ESCESC\ESC\
    Every ESC inside is doubled so tmux hands the whole thing to the outer terminal untouched.
    
            
    trextmuxghostty
    
          
    
          
    
            U+10EEEE · PLACEHOLDER CELLS
            
    U+10EEEE + row U+0305
    + col U+030D · fg 38;5;229
    
          
    
        
    
      
    
      
      
        
    1. 
          01 · DRAW
          
      One tiny framebuffer
      
          
      Every frame is a single 256×144 image painted on the CPU. Sprites, font, lighting and particles are all drawn in code. There are no asset files to ship.
      
          
      
        
      2. 
        
    2. 
          02 · SHIP
          
      Pixels by reference
      
          
      The frame is scaled up by a whole number and dropped into shared memory, with a temp file as backup. Only a short escape crosses the pty, pointing at it. A ring of eight slots keeps the terminal fed.
      
          
      
        
      3. 
        
    3. 
          03 · PASS
          
      Straight through tmux
      
          
      Inside tmux the escape rides DCS passthrough to the real terminal. Same image id every frame, so each new frame simply replaces the last.
      
          
      
        
      4. 
        
    4. 
          04 · PIN
          
      Glued to the pane
      
          
      The picture is placed with Unicode placeholder cells, U+10EEEE plus row and column marks. tmux thinks it is text, so splits, zooms and redraws keep the game exactly where it belongs.

            07the setup
            
      
            Three lines to play.
            
      
            One Rust binary. Ghostty or Kitty to draw it. tmux if you want it next to your work, which you do.
            
    
            
    
            
      
              
        
            1. 
          
              
            
              Install
              
            
              Needs a Rust toolchain. Builds one binary called trex.
              
            
              shell
              

              $ cargo install --git https://github.com/ghandhitechnology/trex
              
          
              
        
              2. 
        
            2. 
          
              
            
              Let tmux pass pixels
              
            
              Passthrough lets kitty graphics out of tmux. Focus events let trex pause when you leave the pane. No tmux? Skip this one.
              
            
              ~/.tmux.conf
              

              set -g allow-passthrough on
set -g focus-events on
              
          
              
        
              3. 
        
            3. 
          
              
            
              Split and play
              
            
              Opens trex in a pane beside whatever is running. Q quits and banks the run.
              
            
              shell
              

              $ tmux split-window -h trex
              
          
              
        
              4. 
      
            
      
              
        
            • TerminalGhostty or Kitty. Anything that speaks kitty graphics with Unicode placeholders.
              • 
        
            • tmux3.3 or newer for allow-passthrough. Or skip tmux and run it bare.
              • 
        
            • Over SSHFrames switch to zlib and travel inside the escape itself, at 30 fps.
              • 
        
            • Frame rate60 fps in a run, 30 in menus, 8 when paused or unfocused.
              • 
        
            • Savetrex/save.ron in your data dir. Bones, unlocks, feats and a best time per dino.
              • 
        
            • SoundNone. Play it on a call.
