    1. 
          01 · DRAW
          
      One tiny framebuffer
      
          
      Every frame is a single 256×144 image painted on the CPU. Sprites, font, lighting and particles are all drawn in code. No asset files ship with it.
      
          
      
        
      2. 
        
    2. 
          02 · SHIP
          
      Pixels by reference
      
          
      The frame is scaled by a whole number and dropped into shared memory. Only a short escape crosses the pty, pointing at it.
      
          
      
        
      3. 
        
    3. 
          03 · PASS
          
      Straight through tmux
      
          
      Inside tmux the escape rides DCS passthrough to the real terminal. Same image id every frame, so each one replaces the last.
      
          
      
        
      4. 
        
    4. 
          04 · PIN
          
      Glued to the pane
      
          
      Placeholder cells pin the picture to the pane, so splits, zooms and redraws keep it right where it belongs.
      
          
      
        
      5. 
        
    5. 
          05 · WAIT
          
      Look away, it waits
      
          
      Switch panes to read your agent's diff and trex pauses itself, then idles at 8 fps until you come back.

        ~ ❯ trex --setup
        
      
        Install, split, play.
        
      
        One Rust binary. Ghostty or Kitty to draw it. tmux if you want it next to your work, which you do.
        
    
        
    
        
      
          
        
        1. 
          
          
            
          Install
          
            
          Needs a Rust toolchain. Builds one binary called trex.
          
            
          shell
          

          $ cargo install --git https://github.com/ghandhitechnology/trex
          
          
          
        
          2. 
        
        2. 
          
          
            
          Let tmux pass pixels
          
            
          Passthrough lets kitty graphics out of tmux. Focus events let trex pause when you leave the pane. No tmux? Skip this one.
          
            
          ~/.tmux.conf
          

          set -g allow-passthrough on
set -g focus-events on
          
          
          
        
          3. 
        
        3. 
          
          
            
          Split and play
          
            
          Opens trex in a pane beside whatever is running. Q quits and banks the run.
          
            
          shell
          

          $ tmux split-window -h trex
          
          
          
        
          4. 
      
        
      
          
        
        • TerminalGhostty or Kitty. Anything that speaks kitty graphics with Unicode placeholders.
          • 
        
        • tmux3.3 or newer for allow-passthrough. Or skip tmux and run it bare.
          • 
        
        • Over SSHFrames switch to zlib and travel inside the escape itself, at 30 fps.
          • 
        
        • Frame rate60 fps in a run, 30 in menus, 8 when paused or unfocused.
          • 
        
        • Savetrex/save.ron in your data dir. Bones, unlocks, feats and a best time per dino.
          • 
        
        • SoundNone. Play it on a call.
