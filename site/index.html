      ~ ❯ trex --help
      
      
      Install, split, play.
      
      
      One Rust binary. Ghostty or Kitty to draw it. tmux if you want it next to your work, which you do.
      
    
      
    
      
      
        
        
      1. 
          
        
            
        Install
        
            
        Needs a Rust toolchain. Builds one binary called trex.
        
            
        shell
        

        $ cargo install --git \
    https://github.com/ghandhitechnology/trex
        
          
        
        
        2. 
        
      2. 
          
        
            
        Let tmux pass pixels
        
            
        Passthrough lets kitty graphics out of tmux. Focus events let trex pause when you leave the pane. No tmux? Skip this one.
        
            
        ~/.tmux.conf
        

        set -g allow-passthrough on
set -g focus-events on
        
          
        
        
        3. 
        
      3. 
          
        
            
        Split and play
        
            
        Opens trex in a pane beside whatever is running. Q quits and banks the run.
        
            
        shell
        

        $ tmux split-window -h trex
        
          
        
        
        4. 
      
      
      
      
      
        
        
      • TerminalGhostty or Kitty. Anything that speaks kitty graphics with Unicode placeholders.
        • 
        
      • tmux3.3 or newer for allow-passthrough. Or skip tmux and run it bare.
        • 
        
      • Over SSHFrames switch to zlib and travel inside the escape itself, at 30 fps.
        • 
        
      • Frame rate60 fps in a run, 30 in menus, 8 when paused or unfocused.
        • 
        
      • Savetrex/save.ron in your data dir. Bones, unlocks, feats and a best time per dino.
        • 
        
      • SoundNone. Play it on a call.
        •
